# KeyShelf

Macのキーボードショートカットを検索・一覧表示する日本語アプリです。SwiftUI / AppKit製。macOS 14以降、外部ライブラリ不要。

## 起動

`build/KeyShelf.app` をFinderからダブルクリックしてください。

```sh
open build/KeyShelf.app
```

ビルド済みアプリはApple Silicon用です。ウインドウを閉じてもメニューバーの⌘アイコンから再表示できます。終了は⌘Q、またはメニューバー内の「終了」です。

## 機能

- 57件の標準ショートカットを6カテゴリに収録：基本操作、Finder、ウインドウとシステム、スクリーンショット、テキスト編集、Safari。
- 操作名、説明、アプリ名、キーで検索。「スクショ」「貼り付け」「cmd c」「shift cmd 4」などに対応。全角・半角、大文字・小文字、ひらがな・カタカナの違いを吸収します。空白や `+` で区切るとすべての語に一致する項目に絞り込みます。
- お気に入り登録と、おすすめ順・名前順の切り替え。
- 詳細欄に大きなキー表示、操作のヒント、修飾キーの読み方、公式資料へのリンク。
- 独自ショートカットの追加・編集・削除。操作名、修飾キー、最後のキー、カテゴリ、アプリ名、メモを保存できます。
- 名前とキーをクリップボードへコピー。
- メニューバーから検索、お気に入り表示、一覧への移動。
- ⌘Fで検索、⌘Nで追加。一覧にフォーカスした状態で↑↓による選択。

登録は早見表へのメモです。macOSや他アプリのキー割り当ては変更しません。使用中のアプリのメニューを自動抽出する機能はありません。ショートカットの動作は、アプリ、キーボード配列、入力ソース、macOSの設定によって異なります。

## データ

お気に入りと独自ショートカットは `~/Library/Application Support/KeyShelf/library.json` にローカル保存します。書き込みはアトミックに行い、保存失敗時には表示も変更しません。読み込みに失敗した場合は元のデータを上書きせず、その起動中の保存を停止してエラーを表示します。

通信、アカウント、利用状況の収集はありません。公式資料のリンクをクリックした場合のみ、ブラウザでAppleのページを開きます。アクセシビリティや画面収録の権限は要求しません。

## ビルド・テスト

```sh
bash Scripts/build.sh
bash Scripts/swift.sh test
```

Xcodeのコマンドラインツールを使用します。Xcodeで `Package.swift` を開いて編集できます。ビルドスクリプトは実行したMac向けのReleaseバイナリとアイコンを.appにまとめ、ローカル実行用のアドホック署名を付けます。Developer ID署名・公証は未実施です。

## 構成

- `Sources/KeyShelfCore`：カタログ、検索、データモデル、JSON保存
- `Sources/KeyShelf`：一覧、詳細、編集、メニューバー、保存状態の管理
- `Tests/KeyShelfCoreTests`：検索、フィルタ、登録編集削除、保存復元、破損データ保護
- `Scripts`：ビルドとアイコン生成
- `Docs/Verification.md`：検証結果
